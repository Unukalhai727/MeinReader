# Mein Reader

梅茵阅读器是一款显示在 Visual Studio Code 底部面板中的本地 TXT 阅读器。它面向个人阅读场景，只保留书库、章节导航、阅读进度和排版设置等必要功能。

所有书籍与阅读数据均保存在本机，不需要账号或网络服务。

## 管理书库

## 导入书籍

1. 点击主页最后一行的“导入书籍”。
2. 在文件选择器中选择一个 TXT 文件。
3. 等待导入完成，书籍将按文件名字典序显示在书库中。

导入完成后，扩展会自动创建原始文件的副本。

如果导入的文件与书库中的书籍同名，新副本会覆盖旧副本，同时保留原有阅读进度。

### 打开书籍

点击书籍所在行即可进入正文页。书名来自 TXT 文件名，不包含 `.txt` 后缀。

### 删除书籍

1. 点击书籍右侧的删除图标，图标会变为红色。
2. 再次点击该图标确认删除。

点击页面其他位置会取消删除确认。

## 阅读界面

正文页顶部提供以下操作：

- **主页**：返回书库。
- **目录**：展开或收起左侧章节目录。
- **上一章 / 下一章**：切换章节，到达书籍边界时自动禁用。
- **设置**：展开或收起右侧排版设置。

目录和设置侧栏不会同时展开。侧栏展开时，点击正文区域也可以将其收起。

扩展每次只渲染当前章节。切换章节或关闭、隐藏阅读面板时会保存当前章节和滚动位置；再次打开书籍时会自动恢复。

## 章节识别

扩展只识别占据完整一行、格式类似以下示例的章节标题：

- `第一章 初见`
- `第十二回 风雪夜归人`
- `第3节 新的开始`

识别规则为：

```text
^[\t \u3000]*第[零〇一二三四五六七八九十百千万两\d]+[章回节卷部篇][^\r\n]*$
```

其他规则：

- 第一章之前存在非空文本时，该部分会单独作为“前言”。
- 未识别到任何章节时，会生成“全文”章节。
- 单个章节超过 100,000 字时会被自动拆分。

## 排版设置

打开正文页右侧的设置侧栏即可即时调整排版。所有设置对整个书库全局生效。

| 设置 | 范围 | 步进 | 默认值 |
| --- | ---: | ---: | ---: |
| 字号 | 12–32 px | 1 px | 18 px |
| 字重 | 250–900 | 10 | 400 |
| 最大页宽 | 480–1600 px | 20 px | 1000 px |
| 字间距 | 0–3 px | 0.1 px | 0.4 px |
| 行间距 | 1.2–2.6 | 0.05 | 1.85 |
| 段间距 | 0–24 px | 1 px | 10 px |

正文使用随扩展提供的思源黑体可变字体。

## 数据与隐私

- 扩展不会上传书籍、阅读进度或设置。
- 扩展不提供账号、云同步或在线书源。

## 支持范围

梅茵阅读器有意保持功能精简，目前不考虑支持：

- EPUB、PDF、MOBI 等非 TXT 格式
- 批量导入或扫描文件夹
- 在线书源
- 账号与云同步
- 阅读笔记、批注或书签
- 自动翻页
- 自定义键盘快捷键
